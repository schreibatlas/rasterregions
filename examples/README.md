# Examples

The `rasterregions_examples/` directory contains deterministic image fixtures and
standalone scripts for the Python API. From the repository root, run the complete
set with:

```bash
python examples/rasterregions_examples/run_all_examples.py
```

The scripts refresh visual and JSON diagnostics under
`examples/rasterregions_examples/outputs/`. These are repository-side examples,
not Python package data, and are excluded from the wheel.

See `rasterregions_examples/README.md` for the fixture and script descriptions.
